# Gemma’s Gems website

This folder is ready to publish with GitHub Pages.

To publish from GitHub:

1. Push the repository to GitHub.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the main branch and the `/docs` folder, then save.
5. Use the resulting HTTPS URLs for the App Store Connect Support URL and Privacy Policy URL.
